How it works

  • Cache read price = if(Model = 1, 0.2, if(Model = 2, 0.1, if(Context re-read per turn (cached) + New context per turn (cache write) > 100, 0.05, 0.01)))
  • Cache write price (5-minute) = if(Model = 1, 5, if(Model = 2, 2.5, if(Context re-read per turn (cached) + New context per turn (cache write) > 100, 0.625, 0.125)))
  • Output price = if(Model = 1, 20, if(Model = 2, 10, if(Context re-read per turn (cached) + New context per turn (cache write) > 100, 2.5, 0.5)))
  • API-equivalent cost per month = (Context re-read per turn (cached) × Cache read price + New context per turn (cache write) × Cache write price (5-minute) + Output per turn × Output price) ÷ 1,000 × Model turns per day × Working days per month
  • Plan price per month = Plan to compare with
  • API cost minus plan price = API-equivalent cost per month - Plan price per month
  • API cost as a share of plan price = 100 × API-equivalent cost per month ÷ Plan price per month

Worked example

With Model = Claude Opus 5.5 (1), Model turns per day = 120 turns, Context re-read per turn (cached) = 60 thousand tokens, New context per turn (cache write) = 3 thousand tokens, Output per turn = 1 thousand tokens, Working days per month = 20 days, Plan to compare with = Max 5x ($100 a month) (100): Cache read price = $0.2 / M tokens, Cache write price (5-minute) = $5 / M tokens, Output price = $20 / M tokens, API-equivalent cost per month = $112.8, Plan price per month = $100, API cost minus plan price = $12.8, API cost as a share of plan price = 113%.

About this tool

This calculator prices your Claude Code usage the way the API would bill it, then sets that figure beside a plan's monthly price. For each model turn it multiplies the thousands of tokens re-read from the cache, newly written to the cache and generated as output by the published price per million tokens, then by your turns per day and working days per month. Plan prices are Pro at $20 a month (or $200 billed up front for a year, which Anthropic shows as $17 a month), Max 5x at $100 and Max 20x at $200. The difference is the API-equivalent cost minus the plan price, so a negative number means the plan costs more than the same usage would at API rates.

Plan limits are not published as token counts, and that is the main limit of any comparison. Anthropic says every plan has usage limits that reset on a rolling five-hour session window, with weekly limits on top for paid plans, and that how much you get depends on the length and complexity of your conversations, the model you choose and the features you use. There is no fixed message or token allowance to divide by, and Claude Code draws from the same pool as your chats. So this page cannot tell you whether your usage would fit inside a plan. It only compares your usage at API rates with the plan price.

Read the percentage as a gauge, not a verdict. A figure well above 100% means the usage would cost more at API rates than the plan does, but only if the plan's limits let you do that much work. A figure well below 100% means pay-as-you-go through an API key would have cost less for that usage, though it would not include the other features of a plan. The defaults (200 turns a day, 80k tokens re-read, 4k new, 1k output, 21 days) are a starting point. Haiku 5.5 is priced higher for prompts over 100,000 tokens (the calculator tests your per-turn average, so sessions with some longer turns can cost more), and cache writes use the 5-minute rate. For your real numbers, run burn, which reads your local Claude Code logs and makes no network calls.

Questions

Do Pro and Max plans charge per token?

No. They are flat monthly prices with usage limits, not per-token billing. Per-token prices apply when you use an API key. Max is monthly only; Pro is $20 billed monthly, or $200 billed up front for a year, which Anthropic shows as $17 a month.

Which API prices does the calculator use?

Anthropic's published prices per million tokens. Opus 5.5: $0.20 cache read, $5 cache write, $20 output. Sonnet 5.5: $0.10, $2.50 and $10. Haiku 5.5: $0.01, $0.125 and $0.50, rising to $0.05, $0.625 and $2.50 for prompts over 100,000 tokens. Cache writes are the 5-minute rate.

Are app-store subscription prices the same?

Not always. Anthropic's Max plan help page says its prices are for web subscriptions and that mobile pricing may vary by app platform. Prices and plans can also change, so check the pricing pages linked under Sources.

What are tokens, context and a turn?

A token is a small piece of text, roughly three quarters of a word. Context is everything Claude Code sends back to the model on each call: your instructions, files it has read and earlier results. A turn is one model call. One message you type can start several turns, one per tool use.
